# Built-in web activity content

**\[experimental\]**

These public content records describe provider-managed web searches and
fetches. They are generated by ellmer when a built-in web tool runs and
can be consumed by user interfaces without parsing provider response
data.

## Usage

``` r
ContentToolRequestSearch(query = stop("Required"), extra = NULL)

ContentToolResponseSearch(sources = list(), extra = NULL)

ContentToolRequestFetch(url = stop("Required"), extra = NULL)

ContentToolResponseFetch(url = NULL, status = NULL, extra = NULL)
```

## Arguments

- query:

  The web search query.

- extra:

  Raw provider-specific metadata, or `NULL`.

- sources:

  A list of
  [WebSource](https://ellmer.tidyverse.org/reference/Source.md) objects
  returned by a search.

- url:

  The URL requested or fetched. Fetch responses may use `NULL` when the
  provider reports a failure without identifying the URL.

- status:

  A normalized fetch outcome: `"success"`, `"error"`, or `NULL` when the
  provider does not report an outcome.

## Value

An S7 object that inherits from
[Content](https://ellmer.tidyverse.org/reference/Content.md).
